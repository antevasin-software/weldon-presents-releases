# Weldon Presents

Installers for Weldon Presents, a presentation app for St Mary's Church, Weldon. This repo holds releases only, not source code.

Download `Weldon-Presents-Setup-<version>.exe` from the [latest release](https://github.com/antevasin-software/weldon-presents-releases/releases/latest) and run it. It needs no admin rights.

Builds are unsigned, so Windows shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**. After that, the app tells you when a new version is available.
